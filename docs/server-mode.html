Edulet 서버 모드 사용법

같은 교실의 PC·휴대폰이 로그인 없이 링크나 QR 로 한 보드를 동시에 쓰는 방법입니다. 유선·무선 모두 되고, 와이파이 주소(IP)가 바뀌는 경우도 다룹니다. 수업 내용을 저장해 두고 되돌리는 법, 보드를 인터넷 없이 볼 수 있는 파일로 내려받는 법도 있어요.

  • 시작하기
  • 안 열릴 때
  • 수업 내용 저장 · 되돌리기
  • 파일로 받아 두기

예전 상태로 되돌리고 싶다 → 4번 · 보드를 파일로 받아 두고 인터넷 없이 보고 싶다 → 5번 (되돌리기용은 아니에요)

1. 세 단계로 시작

  1. 서버 켜기 보드를 열어 둘 PC 에서 run.cmd 를 더블클릭(또는 npm start). 검은 서버 창은 수업이 끝날 때까지 닫지 마세요.
  2. 보드 만들고 공유 교사 PC 브라우저에서 http://localhost:3000 을 열고(처음이면 교사 계정을 가입) 보드를 만든 뒤 공유를 누르면, 링크와 QR 이 다른 기기가 열 수 있는 주소로 나옵니다.
  3. 학생 입장(로그인 없음) 같은 와이파이의 휴대폰은 QR 스캔, PC 는 링크 열기. 이름 입력 창에서 “이름 없이 바로 참여” 한 번이면 끝. 글·댓글이 모두의 화면에 바로 나타나요.

필요한 것: Node.js 22.13 이상, 서버 PC 와 학생 기기가 같은 공유기(같은 와이파이/유선망). 처음 켤 때 뜨는 Windows 방화벽 창에서 개인 네트워크를 체크하고 액세스 허용을 누르세요(안 누르면 다른 기기가 못 들어옵니다).

2. 유선과 무선

서버 PC 를 유선으로서버 PC 를 무선으로
추천가장 안정적. 교사 PC 는 가능하면 유선.가능하지만 주소·연결이 바뀔 수 있음.
학생 기기같은 공유기의 와이파이·유선이면 모두 입장 가능같은 와이파이에 연결
주의유선+무선이 둘 다 켜진 PC 는 주소가 둘. 공유 창의 “공유할 주소”에서 학생들이 쓰는 와이파이와 같은 쪽(보통 192.168.… 또는 10.…)을 고르세요.학교 와이파이가 기기끼리 통신을 막거나(AP 격리) 손님용 와이파이면 안 열려요. 이때는 서버 PC 를 유선으로 옮기세요.

⚠ 무선이면 PC 의 주소(IP)가 바뀔 수 있어요

공유기가 주소를 자동으로 나눠 주기 때문에, 와이파이를 다시 연결하거나 · PC 가 절전에서 깨거나 · 공유기를 껐다 켜거나 · 다른 와이파이로 옮기면 주소가 달라질 수 있습니다(유선도 설정에 따라 바뀝니다). 주소가 바뀌면 이미 보낸 링크·QR 은 열리지 않습니다.

  1. 바로 해결: 교사 PC 에서 공유 창을 다시 엽니다. 열 때마다 현재 주소를 새로 읽어 링크와 QR 을 다시 만들고, 바뀌었으면 알려 줍니다. 학생들은 새 QR 을 다시 스캔하면 됩니다. (서버 창에 처음 찍힌 주소는 켠 순간의 값이라 낡았을 수 있어요.)
  2. 미리 막기: 공유기 설정에서 이 PC 에 고정 IP(“DHCP 예약”·“IP 고정 할당”)를 주거나, 서버 PC 를 유선으로 연결하세요. 학교 공유기를 못 만지면 “수업 시작 전에 QR 을 새로 띄운다”를 습관으로.
  3. 수업 중 한 줄 안내: “안 열리면 칠판의 QR 을 다시 스캔해 주세요.”

주소를 직접 보려면 서버 PC 의 명령 프롬프트에서 ipconfig → Wi-Fi 또는 이더넷 항목의 IPv4 주소. 학생 기기에서 http://그주소:3000 으로 열어도 같습니다.

3. 안 열릴 때

이런 일이…이렇게 확인
다른 기기만 안 열려요Windows 방화벽 허용 — 보안 → 방화벽 및 네트워크 보호 → “방화벽을 통해 앱 허용” → Node.js JavaScript Runtime 의 개인 체크.
“연결할 수 없음”같은 공유기·같은 와이파이인지(손님용 와이파이·AP 격리·VPN 은 안 됩니다). 서버 PC 에서 VPN 이 켜져 있으면 끄기.
어제는 됐는데 오늘은 안 돼요주소가 바뀐 경우가 많아요 → 공유 창을 다시 열어 새 QR.
공유 창에 “이 PC 에서만 열려요”이 PC 의 네트워크 주소를 못 찾은 것(네트워크 미연결, EDULET_HOST=127.0.0.1, Docker). 네트워크에 연결하고 다시 열기.
수업 중 모두 끊겼어요서버 창이 닫혔거나 PC 가 절전에 들어간 것. run.cmd 를 다시 켜고(데이터는 그대로), 설정 → 전원에서 수업 중 절전 안 함.
보드가 비어 있어요GitHub Pages 데모 주소로 열었을 가능성. 데모는 그 브라우저 안에서만 동작해 다른 기기와 공유되지 않습니다. 서버 모드 주소(http://…:3000)로 여세요.
껐다 켰더니 보드가 사라졌어요(빈 화면)다른 폴더에서 켜서 새 빈 data 가 생긴 경우가 많아요 → 아래 “켰더니 보드가 사라졌어요”. 원래 데이터는 그대로 있습니다.
저장하기·불러오기 메뉴가 안 보여요서버 PC 에서 http://localhost:3000 으로 열었는지 확인하세요 → 아래 설명.

4. 수업 내용 저장하기 · 불러오기 (백업과 되돌리기)

평소 작업(보드·글·사진·계정)은 알아서 보관돼요. 서버 창을 닫거나 PC 를 꺼도 run.cmd 가 들어 있는 폴더(이하 프로그램 폴더) 안의 data 폴더에 그대로 남아, 다시 켜면 이어집니다. 다만 이 사본은 이 PC 안에만 있어서 PC 가 고장 나거나 폴더를 지우면 함께 사라져요. 그래서 저장하기로 별도의 사본(저장본)을 만들어 두면 안심이에요.

하고 싶은 일방법
다시 켜기run.cmd 를 더블클릭. 보드·글·사진·교사 계정이 그대로이고, 교사 로그인은 30일 동안 유지됩니다.
학생 다시 입장와이파이 주소가 바뀌었을 수 있어요 → 교사 PC 에서 공유 창을 다시 열어 새 QR. 보드 주소 끝부분(/b/…)은 그대로입니다.

저장하기 — 지금 상태를 저장본으로 남겨 두기 (백업)

수업이 끝난 날, 시험·행사 전, PC 를 바꾸기 전에 한 번 해 두면 마음이 편해요. 서버를 켠 채로, 수업 중에도 됩니다.

  1. 서버를 켠 그 PC 의 브라우저 주소창에 http://localhost:3000 을 입력해 엽니다(‘이 컴퓨터 자신’이라는 뜻이에요).
  2. 위쪽의 저장하기 를 누르고 지금 저장 을 누릅니다. 계정이 있는 서버라면 로그인 창이 뜨니 교사 계정으로 로그인하세요. (보드 화면 안에서는 로그인한 내 이름을 눌러 나오는 메뉴에도 있어요. 메뉴가 안 보이면 아래 “메뉴가 안 보여요”.)
  3. 저장한 시각과 보드·글·사진 개수가 나오면 성공입니다. ‘알려 드릴 점’이 함께 나오면 한 번 읽어 보세요.

저장본은 프로그램 폴더 안의 backups 폴더에 edulet-날짜-시간 이름으로 생깁니다. 그 폴더를 USB 나 나만 쓰는 클라우드 폴더(공유를 끈 것)에 복사해 두면 PC 가 고장 나도 안전하고, 다른 PC 로 옮길 수도 있어요.

  • 저장본에는 학생 이름·글·계정 정보가 모두 들어 있어요. 다른 사람에게 보내거나 공개된 곳에 올리지 마세요.
  • 저장본은 저절로 지워지지 않고 쌓여요(불러오기 직전의 ‘자동 저장’도 마찬가지예요). 오래된 것은 backups 안의 edulet-… 폴더만 지우세요. data 폴더는 절대 지우지 마세요.
  • 아직 “게시하기”를 누르지 않은 작성 중인 글은 그 브라우저에만 있어서 저장본에 담기지 않아요.

불러오기 — 저장해 둔 것 중 하나로 되돌리기

불러오기는 지금의 보드·글을 고른 저장본의 모습으로 통째로 바꾸는 일이에요. 수업 중이 아닐 때 하세요(접속 중인 학생들의 화면도 새로고침돼서, 아직 게시하지 않고 쓰던 글은 사라져요).

  1. 같은 화면(localhost)에서 위쪽의 불러오기 를 누르면 저장본 목록이 최신 순으로 나옵니다. 직접 저장 은 내가 저장하기로 만든 것, 자동 저장 은 불러오기 직전에 프로그램이 대신 만들어 둔 것이에요.
  2. 하나를 누르면 미리보기(어떤 보드가 있는지, 지금과 비교해 글이 몇 개 달라지는지)가 나옵니다.
  3. 이 저장본으로 불러오기… 를 누르고, 안내를 읽은 뒤 확인 창에서 같은 이름의 단추를 한 번 더 누르면 시작돼요.
  4. 끝나면 화면이 새로고침돼요. 저장했을 때의 보드와 글이 보이면 성공입니다.

잘못 불러왔어도 괜찮아요. 불러오기 직전의 지금 데이터를 자동 저장으로 먼저 남겨 두기 때문에, 같은 방법으로 목록에서 그 ‘자동 저장’을 고르면 원래대로 돌아옵니다. 불러오기가 도중에 실패하면 지금 데이터는 바뀌지 않고 그대로 남아요.

알아 두세요

  • 저장본을 만든 뒤에 새로 쓰거나 고친 글은 불러오면 사라져요(그래서 ‘자동 저장’이 따로 남습니다).
  • 계정·비밀번호도 저장했을 때로 돌아가요. 저장 뒤에 가입한 계정은 없어지고, 로그인이 풀리면 저장본에 있던 계정으로 다시 로그인하세요.
  • 데이터가 많으면 몇 초 걸리고, 그동안 서버가 잠시 느려질 수 있어요.

다른 PC 로 옮기려면 옛 PC 의 backups 안에 있는 edulet-… 폴더를 새 PC 의 backups 폴더에 복사하세요(backups 폴더가 없으면 새로 만드세요). 그러면 새 PC 의 불러오기 목록에 나타납니다. 새 PC 에서는 처음 한 번 교사 계정을 가입해 로그인해야 불러오기를 쓸 수 있어요. 불러오고 나면 그 임시 계정은 없어지니, 저장본에 있던 계정으로 다시 로그인하세요.

저장하기·불러오기 메뉴가 안 보여요

저장하기·불러오기는 서버 PC 에서 http://localhost:3000 으로 연 화면에서만 보여요. 학생이 실수로 건드리지 못하게 일부러 막아 둔 것이라, 아래 경우에는 안 보이는 것이 정상이에요.

  • 학생들의 휴대폰·다른 PC 에서 연 화면
  • 서버 PC 에서도 공유 링크(192.168.… 같은 숫자 주소)로 연 화면 → 주소창을 http://localhost:3000 으로 바꿔 보세요.
  • GitHub Pages 데모 사이트(서버 모드가 아니에요)

그래도 안 되면 프로그램 폴더의 backup.cmd 를 더블클릭하세요(아래 ‘고급’). 서버 PC 를 학생과 같이 쓴다면 그 PC 에서 가입한 누구나 저장·불러오기를 할 수 있으니 새 가입을 막아 두세요(방법은 아래 ‘고급’).

⚠ 켰더니 보드가 사라졌어요 (빈 화면)

데이터는 서버를 시작한 폴더 기준의 data 에 만들어집니다. run.cmd 는 항상 자기 폴더에서 시작하도록 고쳐져 있지만, node server\index.js 를 다른 폴더에서 직접 켜거나 예전 판 run.cmd 를 바로가기·작업 표시줄·작업 스케줄러로 켰다면 그 폴더에 새 빈 data 가 생겼을 수 있습니다. 원래 data 는 지워지지 않고 그대로 있어요.

  1. 서버 창을 닫습니다.
  2. 원래 데이터는 run.cmd 가 있는 프로그램 폴더 안의 data 입니다. 그 폴더의 run.cmd 를 더블클릭해 다시 켜면 그대로 돌아옵니다.
  3. 엉뚱한 위치에 새로 생긴 빈 data 폴더는 그냥 두어도 됩니다(헷갈리면 지우지 마세요).

아예 고정하기 (고급 — 잘 모르면 건너뛰어도 돼요) — 명령 프롬프트에서 한 번만 실행하면 이후 어떻게 켜도 항상 그 폴더를 씁니다(실행 뒤에는 run.cmd 를 새로 켜세요. 적용이 안 되면 PC 를 한 번 다시 시작):

setx EDULET_DATA_DIR "D:\EduletData"
고급 — 화면을 쓸 수 없을 때 backup.cmd 로 저장 · 손으로 복원 · 새 가입 막기
하고 싶은 일방법
백업 화면을 쓸 수 없을 때backup.cmd 를 더블클릭 — 서버를 켠 채로 해도 됩니다(수업 중에도 안전해요). 프로그램 폴더 안에 backups\edulet-날짜-시간 폴더가 새로 생기고, 그 폴더를 USB·클라우드에 복사해 두면 됩니다. 원본 data 는 읽기만 하고 바꾸지 않아요. 폴더 안 BACKUP-INFO.txt 에 보드·글·사진 개수와 복원 방법이 적혀 있습니다. 끝나면 “가장 최근 글” 시각이 방금까지의 작업과 맞는지 한 번 봐 주세요. (서버 창을 닫은 뒤 data 폴더 전체를 복사해도 같은 효과예요.)
결과 읽는 법: 마지막에 Backup FAILED 면 실패(만들던 폴더는 지워지고 원본은 그대로) · Backup finished WITH WARNINGS 면 백업은 만들어졌지만 일부 파일이 빠졌을 수 있어요(위쪽 “경고” 줄을 읽어 보세요) · 경고 없이 끝나면 완전한 백업입니다. 프로그램으로 부르는 경우 종료 코드는 0 = 완전 · 1 = 실패 · 2 = 경고 있음.
이름 끝에 .partial 이 붙은 폴더(edulet-….partial)는 백업이 중간에 끊긴 것(창을 닫거나 전원이 나간 경우)이니 쓰지 말고 지워도 됩니다. 정상 이름의 폴더는 끝까지 만들어 확인을 마친 것만 있어요.
복원 · 다른 PC 로 옮기기 화면을 쓸 수 없을 때아래 복원 방법대로 백업 폴더의 edulet.db 와 uploads 를 새 data 폴더에 넣고 run.cmd. 프로그램과 data 폴더를 통째로 옮겨도 됩니다(Node.js 가 있는 PC). 데이터를 다른 위치에 두려면 환경변수 EDULET_DATA_DIR 로 폴더를 지정하세요.
새 가입 막기 학생과 같이 쓰는 서버 PC교사 계정을 먼저 가입해 둔 뒤에, 명령 프롬프트에서 setx EDULET_ALLOW_REGISTER 0 을 한 번 실행하고 run.cmd 로 서버를 다시 켜세요. 이미 있는 계정은 그대로 쓰고, 새 가입은 (교사 가입도) 막혀요. (되돌리려면 setx EDULET_ALLOW_REGISTER 1)

⚠ 서버가 켜져 있을 때 edulet.db 만 복사하면 비어 있거나 낡은 백업이 됩니다

서버가 켜진 동안 edulet.db 는 낡은 값입니다(비어 있거나 최근 작업이 빠진 파일). 방금까지의 작업은 edulet.db-wal 에 쌓여 있고, edulet.db 만 복사하면 그 작업이 빠진 백업이 됩니다. 폴더 통째로(서버를 끈 뒤) 복사하거나, backup.cmd 를 쓰세요.

  • backup.cmd 는 이 프로그램 폴더의 data 를 백업합니다. 서버를 켤 때 EDULET_DATA_DIR 를 썼다면 backup.cmd 를 실행하는 창에도 같은 환경변수가 필요해요(setx 로 고정했다면 둘 다 자동). 그렇지 않으면 이 폴더에 남아 있는 옛 data 를 “성공”으로 백업합니다 — 서버를 다른 폴더에서 켠 경우도 같아요. 이럴 땐 backup.cmd --data "그폴더\data" 로 알려 주세요.
  • 그래서 백업이 끝나면 원본 폴더 · 가장 최근 글 시각 · 원본 WAL 마지막 수정 시각을 보여 줍니다. 방금 쓴 글의 시각과 다르거나 “글이 하나도 없어요” 경고가 나오면 엉뚱한 data 를 백업한 것이니 위처럼 폴더를 지정해 다시 하세요. 그 data 가 없으면 “data 폴더를 찾을 수 없어요”라고 알려 주고 아무것도 만들지 않습니다.
  • 사진·파일이 든 uploads 폴더를 다른 드라이브로 옮겨 바로가기(링크)로 연결했어도 그대로 따라가서 백업하고, 그렇다고 알려 줍니다(경고로 취급 — 종료 코드 2). 업로드 파일 하나가 바로가기이거나 다른 프로그램이 잠그고 있으면 그 파일만 건너뛰고 알려 줍니다.

복원 방법 — 손으로 (화면의 불러오기를 쓸 수 없을 때. BACKUP-INFO.txt 에도 같은 내용이 있어요)

BACKUP-INFO.txt 가 있는 정상 이름(edulet-날짜-시간)의 폴더만 쓰세요. 이름 끝에 .partial 이 붙은 폴더는 중간에 끊긴 것이니 쓰지 말고 지워도 됩니다.

  1. 서버를 끕니다(서버 창을 닫기).
  2. 지금의 data 폴더를 따로 옮겨 둡니다(지우지 말고 이름만 바꾸거나 다른 곳으로).
  3. 새 data 폴더를 만들고, 백업 폴더의 edulet.db 와 uploads 폴더를 그 안에 복사합니다.
  4. 새 data 폴더에 옛 edulet.db-wal · edulet.db-shm 파일이 있으면 반드시 지웁니다. (남아 있으면 다른 데이터베이스의 WAL 이 복원본에 다시 적용돼 데이터가 망가질 수 있어요.)
  5. run.cmd 로 서버를 켭니다. 다른 위치의 data 폴더를 쓰려면 환경변수 EDULET_DATA_DIR 로 그 폴더를 지정하세요.

5. 보드를 HTML 파일로 받아 두기 (인터넷 없이 보기)

보드를 파일 하나로 내려받아 두면, 인터넷이나 서버가 없어도 그 파일을 더블클릭해 브라우저로 볼 수 있어요. 글·댓글·반응·그림·첨부 파일이 모두 들어갑니다(링크와 유튜브 같은 영상은 주소만 들어가서, 눌러 보려면 인터넷이 필요해요). 수업 결과물을 보관하거나, 메일·USB 로 건넬 때 좋아요. 인터넷 없는 교실에서 보려면 미리 이 파일을 USB 나 그 교실 PC 에 복사해 두세요. 거기서는 파일만 더블클릭하면 됩니다. (되돌리기용은 아니에요 — 되돌리기는 위의 4번.)

  1. 내보내기 누르기 보드 화면 위쪽의 내보내기 → HTML 파일 (오프라인). (내 보드 목록에서는 보드 카드의 메뉴 → HTML 로 내보내기. 이쪽은 옵션 없이 바로 만들어요.)
  2. 옵션 고르기 그림 크기는 ‘줄여서(권장)’면 파일이 작아져요. 첨부 파일(PDF 등)도 담기 는 체크한 채로 두세요.
  3. 파일 열기 진행 막대가 끝나면 브라우저의 다운로드 폴더(보통 ‘다운로드’)에 edulet-…-날짜.html 파일이 생겨요(브라우저에 뜨는 다운로드 표시를 눌러도 열려요). 더블클릭하면 브라우저에서 열립니다.

알아 두세요

  • 사진 찍어 둔 것처럼 그 순간의 모습이에요. 파일 안에서 글을 쓰거나 실시간으로 바뀌지는 않고, 다시 보드로 불러올 수도 없어요. (카드를 자유롭게 놓는 ‘캔버스’ 보드는 위치가 담기지 않고 읽는 순서대로 격자에 늘어놓아요.)
  • 보낼 때는 조심하세요. 이름·글·그림이 모두 들어 있어요. 그림은 ‘줄여서’일 때 촬영 위치 같은 정보가 빠지고, ‘원본 크기’일 때는 그대로 들어가요. 보드를 볼 수 있는 사람이면 학생도 자기 기기에서 내려받을 수 있고(자기에게 보이는 글만 담겨요), 관리 권한이 있는 사람이 내보내면 승인을 기다리는 글도 담겨요.
  • 열어도 안전해요. 파일에는 실행되는 프로그램이 들어 있지 않고 열 때 저절로 인터넷에 접속하지도 않아서, 학생이 쓴 내용이 있어도 열 때 위험하지 않아요.
  • 그림이 많으면 파일이 커져요. 너무 크면 메일에는 첨부하기 어려울 수 있어요. 아주 큰 첨부는 담기지 않고 무엇이 빠졌는지 파일 안에 적어 둬요. 글만으로도 너무 크면 보드를 나눠서 내보내 달라고 안내해요.

엑셀로 보고 싶다면 같은 곳의 CSV 파일 (엑셀), 데이터 그대로는 JSON 파일을 받으세요(읽기용이고 다시 불러오기는 안 돼요). 같은 서버 안에서 보드를 통째로 복사하는 것은 복제입니다.

6. 알아 두기

  • 권한: 공유 창에서 공개 범위가 “링크가 있는 누구나”여야 로그인 없이 들어오고, 링크 권한(댓글 달기/글쓰기)으로 올릴 수 있는 범위를 정합니다.
  • 데이터: data 폴더 안에 저장됩니다(보드·글·사진) — 저장하기·불러오기는 위 4번, 파일로 내려받기는 5번.
  • 입장 폭주: 한꺼번에 많이 들어오면 “N초 뒤에 자동으로 다시 시도해요”가 뜨고 알아서 입장합니다.
다른 건물·집에서도 접속하게 하려면(인터넷 공개, 선택)

서로 다른 네트워크에서 쓰려면 바깥에서 열 수 있는 주소가 필요합니다. Cloudflare Tunnel·ngrok 같은 터널로 3000 포트를 열거나 클라우드/학교 서버에 Docker 로 올리고, 서버에 그 주소를 알려 주세요.

EDULET_PUBLIC_URL=https://edulet.example.com
EDULET_TRUST_PROXY=1
EDULET_COOKIE_SECURE=1

(Windows 명령 프롬프트는 줄마다 set 이름=값 한 뒤 npm start.) 인터넷에 공개하면 누구나 링크로 들어올 수 있으니 공개 범위·링크 권한을 꼭 확인하세요. 이렇게 공개한 서버에서는 저장하기·불러오기 메뉴가 나오지 않아요(위 4번). 자세한 설정은 저장소 README 의 “다른 PC 와 함께 쓰기”.

Edulet · 이 안내서는 한 파일(docs/server-mode.html)로 되어 있어 내려받아 브라우저로 열거나 인쇄해도 됩니다.
